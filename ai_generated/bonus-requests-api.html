دوره‌ی مقدماتی پایتون برای علم داده

گرفتن داده از اینترنت با requests

تا اینجا از فایل CSV داده خواندیم؛ اما خیلی از داده‌های واقعی (مثل قیمت ارز یا آب‌وهوا) از یک API روی اینترنت می‌آیند. این بخش کوتاه و اختیاری، خارج از ۹ بخش اصلی دوره، همین را نشان می‌دهد.

⏱ حدود ۲۰ دقیقه 🌐 requests + JSON
In [1]:
import requests

url = "https://api.coingecko.com/api/v3/simple/price"
response = requests.get(url, params={"ids": "bitcoin", "vs_currencies": "usd"})

data = response.json()
print(data)
Out[1]: 
{'bitcoin': {'usd': 61234}}

یک درخواست ساده، قدم‌به‌قدم

requests.get(url) یک درخواست به سرور می‌فرستد؛ response.json() پاسخ (که معمولاً به فرمت JSON است) را به یک دیکشنری یا لیست پایتون تبدیل می‌کند — دقیقاً همان ساختارهایی که در جلسه‌ی دوم یاد گرفتیم.

مدیریت خطا با try/except

اینترنت همیشه در دسترس نیست و سرورها گاهی خطا می‌دهند؛ برای اینکه برنامه با یک خطای شبکه کاملاً متوقف نشود، درخواست را داخل try/except قرار می‌دهیم:

In [2]:
try:
    response = requests.get(url, params={"ids": "bitcoin", "vs_currencies": "usd"}, timeout=10)
    response.raise_for_status()   # اگر کد وضعیت خطا بود (مثل 404)، خطا صادر می‌کند
    data = response.json()
except requests.exceptions.RequestException as e:
    print("خطا در دریافت داده:", e)
💡 timeout=10 یعنی اگر سرور تا ۱۰ ثانیه پاسخ نداد، به‌جای معطل‌ماندن، خطا صادر شود.

مرحله‌ی بعد

با ترکیب requests، pandas و Matplotlib می‌توان تاریخچه‌ی قیمت را هم گرفت، در قالب جدول تحلیل کرد و نمودار روند را رسم کرد — نسخه‌ی کامل همین ایده، با ذخیره‌ی خودکار خروجی، در پروژه‌ی جایزه‌ی دوره آماده است.
