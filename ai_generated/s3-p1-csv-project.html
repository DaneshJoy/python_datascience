پردازش CSV و پروژه‌ی تحلیل داده

جلسه‌ی دوم تمام شد 🎉 حالا وقتشه همه‌چیز را کنار هم بگذاریم: یک پروژه‌ی کامل تحلیل داده، از خواندن فایل CSV تا ذخیره‌ی نتیجه‌ی نهایی.

⏱ حدود ۶۰ دقیقه 📁 پروژه‌ی CSV
In [1]:
import pandas as pd

df = pd.read_csv("people.csv")
print(df.head(3))
Out[1]: 
    name  height_cm  weight_kg
0    آرش        178         82
1   نگار        165         58
2  رامین        172         75

هدف پروژه

یک فایل CSV داریم با نام، قد (بر حسب سانتی‌متر) و وزن (بر حسب کیلوگرم) چند نفر. می‌خواهیم برای هرکدام BMI را حساب کنیم، وضعیت‌شان را دسته‌بندی کنیم، و نتیجه را ذخیره کنیم — دقیقاً همان کاری که یک تحلیل‌گر داده‌ی واقعی هر روز انجام می‌دهد.

قدم ۱: خواندن و بررسی داده

In [2]:
print(df.shape)
print(df.describe())
Out[2]: 
(50, 3)

shape نشان می‌دهد جدول ۵۰ سطر و ۳ ستون دارد؛ describe() هم میانگین، کمینه و بیشینه‌ی ستون‌های عددی را خلاصه می‌کند.

قدم ۲: تبدیل واحد قد

فرمول BMI به متر نیاز دارد، اما داده‌مان بر حسب سانتی‌متر است؛ پس یک ستون جدید می‌سازیم:

In [3]:
df["height_m"] = df["height_cm"] / 100

قدم ۳: محاسبه‌ی BMI برای همه

نیازی به حلقه نیست — Pandas عملیات را روی کل ستون، یک‌جا انجام می‌دهد:

In [4]:
df["bmi"] = df["weight_kg"] / (df["height_m"] ** 2)
print(df[["name", "bmi"]].head(3))
Out[4]: 
    name    bmi
0    آرش  25.88
1   نگار  21.30
2  رامین  25.35

قدم ۴: دسته‌بندی وضعیت با تابع

همان تابعی که در جلسه‌ی اول نوشتیم را این‌بار روی کل ستون BMI اجرا می‌کنیم — با apply:

In [5]:
def bmi_status(bmi):
    if bmi < 18.5:
        return "کمبود وزن"
    elif bmi < 25:
        return "طبیعی"
    elif bmi < 30:
        return "اضافه‌وزن"
    else:
        return "چاق"

df["status"] = df["bmi"].apply(bmi_status)
print(df[["name", "bmi", "status"]].head(3))
Out[5]: 
    name    bmi     status
0    آرش  25.88  اضافه‌وزن
1   نگار  21.30     طبیعی
2  رامین  25.35  اضافه‌وزن

قدم ۵: ذخیره‌ی نتیجه

In [6]:
df.to_csv("bmi_results.csv", index=False)
df.to_excel("bmi_results.xlsx", index=False)
✅ همین چند خط، یک پروژه‌ی واقعی و کامل تحلیل داده است: خواندن، پردازش، محاسبه و ذخیره.

جمع‌بندی این بخش

  • یک فایل CSV واقعی را با Pandas خواندیم و بررسی کردیم
  • واحدها را تبدیل و ستون BMI را برای همه محاسبه کردیم
  • با یک تابع، وضعیت هر فرد را دسته‌بندی کردیم
  • نتیجه را در چند فرمت مختلف ذخیره کردیم
