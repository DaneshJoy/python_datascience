# کدهای پروژه‌های دوره

پنج اسکریپت مستقل پایتون، هرکدام مرور یک بخش از دوره — کوتاه، اجراپذیر و با کامنت فارسی.

| فایل | مرتبط با | خلاصه |
|---|---|---|
| `01_basics_gradebook.py` | بخش‌های ۱ تا ۳ | متغیر، لیست، دیکشنری، حلقه، شرط، f-string |
| `02_bmi_calculator.py` | بخش ۲ و ۳ | گزارش BMI با f-string + دریافت مجدد ورودی معتبر با while/try |
| `03_numpy_matplotlib_demo.py` | بخش ۵ و ۸ | ساخت داده با NumPy، آنالیز آماری، نمودار با Matplotlib |
| `04_csv_stackoverflow_trends.py` | بخش ۷ و ۸ | خواندن/پردازش CSV، ایجاد دایرکتوری خروجی، ذخیره‌ی نتیجه و نمودار |
| `05_bonus_crypto_prices.py` | جایزه | دریافت آنلاین قیمت بیت‌کوین (API رایگان CoinGecko) و تحلیل روند |

## اجرا

```bash
pip install -r requirements.txt
python 01_basics_gradebook.py
```

هر فایل را جداگانه و به همین شکل اجرا کنید.

## نکته‌ی مهم درباره‌ی فایل ۴ (داده‌ی StackOverflow)

این اسکریپت به‌صورت پیش‌فرض دنبال فایلی به نام `data/stackoverflow_trends.csv` می‌گردد. **فایل واقعی خودتان را با همین نام در پوشه‌ی `data/` قرار دهید** (یا مقدار `INPUT_FILE` در کد را به مسیر فایل خودتان تغییر دهید).

ستون‌های موردانتظار: یک ستون `Year` + یک ستون برای هر زبان برنامه‌نویسی (مقدار = تعداد یا درصد پست‌ها). اگر ساختار فایل شما فرق دارد، فقط بخش خواندن و `melt` را متناسب با ستون‌های خودتان تغییر دهید — بقیه‌ی منطق (تحلیل، ذخیره، نمودار) همان می‌ماند.

اگر فایل پیدا نشود، اسکریپت به‌طور خودکار یک نمونه‌ی آزمایشی (با اعداد فرضی، نه واقعی) می‌سازد تا کد قابل‌اجرا و قابل‌تست بماند.

## نکته درباره‌ی فایل ۵ (کریپتو)

داده از API رایگان [CoinGecko](https://www.coingecko.com/en/api) گرفته می‌شود و نیاز به اینترنت دارد؛ در نبود اینترنت، اسکریپت به‌طور خودکار روی داده‌ی نمونه سوییچ می‌کند. این کد صرفاً برای تمرین «دریافت داده از اینترنت + pandas + رسم نمودار» است و نباید مبنای تصمیم مالی قرار گیرد.

## خروجی‌ها

فایل‌های ۴ و ۵ به‌طور خودکار یک پوشه‌ی `output/` می‌سازند و نتایج (CSV و نمودار PNG) را در آن ذخیره می‌کنند.
