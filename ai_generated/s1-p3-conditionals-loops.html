شرط‌ها، حلقه‌ها و تکمیل پروژه‌ی BMI

در بخش قبل متغیرها و عملگرها را یاد گرفتیم؛ در این بخش با شرط‌ها و حلقه‌ها تصمیم‌گیری و تکرار را به کدمان اضافه می‌کنیم و پروژه‌ی BMI را کامل می‌کنیم.

⏱ حدود ۶۰ دقیقه ✅ تکمیل پروژه BMI
In [1]:
score = 78

if score >= 90:
    grade = "A"
elif score >= 70:
    grade = "B"
else:
    grade = "C"

print(f"نمره‌ی نهایی: {grade}")
Out[1]: 
نمره‌ی نهایی: B

دستورات شرطی

با if می‌توان بر اساس درست یا نادرست بودن یک شرط، مسیر اجرای برنامه را تغییر داد. هر if می‌تواند چند elif و در پایان تنها یک else داشته باشد. نکته‌ی مهم: دستورهای داخل هر شرط باید دقیقاً به اندازه‌ی ۴ فاصله (یا یک Tab) از ابتدای خط فاصله داشته باشند — این تورفتگی در پایتون اجباری است، نه فقط برای زیبایی.

In [2]:
if condition1:
    # این خط اجرا می‌شود
elif condition2:
    # یا این خط
else:
    # یا این خط

تکمیل پروژه: دسته‌بندی وضعیت BMI

حالا که if و elif را داریم، می‌توانیم بر اساس عدد BMI محاسبه‌شده، وضعیت فرد را هم مشخص کنیم:

بازه‌ی BMIوضعیت
کمتر از ۱۸.۵کمبود وزن
۱۸.۵ تا ۲۴.۹طبیعی
۲۵ تا ۲۹.۹اضافه‌وزن
۳۰ تا ۳۴.۹چاقی درجه‌ی ۱
۳۵ تا ۳۹.۹چاقی درجه‌ی ۲
بیشتر از ۴۰چاقی درجه‌ی ۳
In [3]:
weight = 68
height = 1.72
bmi = weight / height ** 2

if bmi < 18.5:
    status = "کمبود وزن"
elif bmi < 25:
    status = "طبیعی"
elif bmi < 30:
    status = "اضافه‌وزن"
else:
    status = "چاق"

print(f"BMI شما: {bmi:.2f} → {status}")
Out[3]: 
BMI شما: 22.99 → طبیعی

حلقه‌ی for

حلقه‌ی for روی آیتم‌های یک مجموعه (مثل لیست) حرکت می‌کند و برای هرکدام، دستورهای داخل حلقه را اجرا می‌کند.

In [4]:
languages = ["Python", "C#", "Rust", "Dart"]

for lang in languages:
    print(f"من عاشق {lang} هستم! ❤️")
Out[4]: 
من عاشق Python هستم! ❤️
من عاشق C# هستم! ❤️
من عاشق Rust هستم! ❤️
من عاشق Dart هستم! ❤️

range و enumerate

range(start, stop, step) دنباله‌ای از اعداد می‌سازد؛ و اگر هم به مقدار و هم به شماره‌ی هر آیتم نیاز داشته باشید، enumerate کار را راحت می‌کند.

In [5]:
for i, lang in enumerate(languages, start=1):
    print(i, lang)
Out[5]: 
1 Python
2 C#
3 Rust
4 Dart
💡 نکته‌ی جلوتر: [n**2 for n in range(1, 6)] همین حلقه را در یک خط می‌نویسد و [1, 4, 9, 16, 25] می‌سازد — به آن List Comprehension می‌گویند و در جلسه‌ی بعد بیشتر می‌بینیمش.

حلقه‌ی while

وقتی از قبل نمی‌دانیم حلقه چند بار تکرار می‌شود و فقط یک شرط توقف داریم، از while استفاده می‌کنیم.

In [6]:
count = 3
while count > 0:
    print("شمارش معکوس:", count)
    count -= 1
print("🚀 پرتاب!")
Out[6]: 
شمارش معکوس: 3
شمارش معکوس: 2
شمارش معکوس: 1
🚀 پرتاب!
