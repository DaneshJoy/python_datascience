پروژه‌ی پایانی: از داده تا نمودار

در این پروژه، یک فایل فروش ماهانه را می‌خوانیم، سودآورترین ماه‌ها را پیدا می‌کنیم و نتیجه را رسم می‌کنیم — دقیقاً چیزی که هر سه جلسه‌ی دوره را در چند خط کنار هم می‌گذارد:

In [2]:
import pandas as pd
import matplotlib.pyplot as plt

sales = pd.read_csv("monthly_sales.csv")
sales["profit"] = sales["revenue"] - sales["cost"]

top = sales.sort_values("profit", ascending=False).head(3)
print(top[["month", "profit"]])

top.plot(x="month", y="profit", kind="bar", color="#1F4E79")
plt.title("پرسودترین ماه‌ها")
plt.savefig("top_months.png")
Out[2]:

مسیر ادامه‌ی یادگیری

این دوره فقط شروع راه بود. برای ادامه، این مسیرها پیشنهاد می‌شود:

یادگیری ماشین با Scikit-learn

گام بعدی طبیعی بعد از Pandas؛ ساخت اولین مدل پیش‌بینی با داده‌های خودت.

SQL و پایگاه‌داده

اغلب داده‌های واقعی در دیتابیس‌اند، نه فایل CSV؛ SQL برای رسیدن به آن‌ها ضروری است.

Git و GitHub

برای نگه‌داری نسخه‌های کد و اشتراک‌گذاری پروژه‌ها، ابزار استاندارد صنعت.

تمرین با پروژه‌های واقعی

سایت‌هایی مثل Kaggle داده‌های واقعی رایگان برای تمرین در اختیارت می‌گذارند.

حرف آخر

یاد گرفتن برنامه‌نویسی از روی تماشا اتفاق نمی‌افتد؛ از روی نوشتن و خراب‌کاری و دوباره درست کردن کد اتفاق می‌افتد. حالا که پایه‌ها را داری، بهترین کار این است که یک داده‌ی واقعی — حتی داده‌های خودت — را برداری و همین مسیر را از اول تا آخر روی آن پیاده کنی. موفق باشی 🐍
