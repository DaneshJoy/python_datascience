نصب کتابخانه‌ها و آشنایی با NumPy

در بخش قبل با ساختارهای داده و توابع آشنا شدیم؛ حالا یاد می‌گیریم چطور کتابخانه نصب کنیم و با NumPy — پایه‌ی محاسبات عددی در پایتون — کار کنیم.

⏱ حدود ۶۰ دقیقه 📦 نصب کتابخانه
In [1]:
import numpy as np

prices = np.array([120000, 89000, 45000])
print(prices * 0.9)
Out[1]: 
[108000.  80100.  40500.]

کتابخانه (ماژول) چیست؟

کتابخانه مجموعه‌ای از کدهای آماده است که با import وارد برنامه می‌شود تا نیازی به نوشتن دوباره‌ی آن‌ها نباشد.

دستورکاربرد
import sysوارد کردن کل ماژول
import pandas as pdوارد کردن با نام مستعار (خلاصه‌تر)
from sys import versionوارد کردن فقط یک بخش خاص

نصب و مدیریت کتابخانه‌ها

در محیط Anaconda، دو ابزار برای نصب کتابخانه در دسترس است: pip (استاندارد پایتون) و conda (مخصوص Anaconda). هر دو را می‌توان در Anaconda Prompt یا ترمینال اجرا کرد.

عملیاتبا pipبا conda
نصب پکیجpip install pandasconda install pandas
لیست پکیج‌های نصب‌شدهpip listconda list
مشاهده‌ی جزئیات پکیجpip show pandasconda list pandas
حذف پکیجpip uninstall pandasconda remove pandas
💡 پکیج‌های پایتون معمولاً از مخزن PyPI (برای pip) یا مخزن Anaconda و conda-forge (برای conda) دانلود می‌شوند.

چرا NumPy؟

لیست‌های پایتون برای کارهای عمومی خوب‌اند، اما برای محاسبات عددی روی داده‌های بزرگ کند هستند. NumPy یک ساختار به نام «آرایه» (array) معرفی می‌کند که محاسبات را روی کل مجموعه‌ی داده، یک‌جا و بسیار سریع انجام می‌دهد — دقیقاً همان‌طور که در نمونه‌ی بالا دیدید: ضرب کل لیست قیمت‌ها در ۰.۹ فقط با یک خط.

In [2]:
import numpy as np

grades = np.array([18, 15, 19, 12, 20])

print("میانگین:", grades.mean())
print("بیشترین:", grades.max())
print("شکل آرایه:", grades.shape)
Out[2]: 
میانگین: 16.8
بیشترین: 20
شکل آرایه: (5,)

آرایه‌های NumPy همانند لیست‌ها ایندکس‌گذاری و برش می‌شوند، اما علاوه بر آن می‌توانند دوبعدی (مثل یک جدول یا ماتریس) هم باشند — چیزی که در Pandas، در بخش بعد، پایه‌ی کار با جدول داده خواهد بود.
